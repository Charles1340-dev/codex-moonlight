# 本地素材与 Mini 接入

公开源码和程序可播放通用航海开场、预览主题和导出默认主题。角色插画和视频是可选本地内容，不会自动从网上下载，也不包含在公开 Release。请使用自己有权使用的素材。

## 目录

将素材放在 MoonlightCodex.exe 同级目录的 local-themes/voyage；开发时放在项目根目录的同一路径。不得把 private 素材目录提交到仓库。

| 文件 | 用途 |
| --- | --- |
| ships-v2.png | 首选双船图集，1536 × 1024，左右图同高 |
| ships.png | 旧版双船图集兼容入口 |
| chapter-board-*.webp | 章节背景，裁切约定见 src/chapter-art.mjs |
| forms-full.png | 六种推理形态及菜单图标 |
| effort-film-forward、reverse、laugh、laugh-reverse.webm | 完整变身、反向和大笑透明视频 |
| pet-motion-动作.webm | 常态完整人物动作 |
| pet-motion-snakeman-动作.webm | 蛇人完整人物动作 |
| pet-motion-nika-动作.webm | 五档完整人物动作 |

各形态的日常动作名为 idle、walk、wave、inspect、bite、chew、happy、sleep、jump、stretch。起停片段为 walkin、walkout、walkback；18 个招式按 desktop/pet-moves.json 的 id 命名。当前视频为透明 VP9 WebM、432 × 492、60 fps；每个动作应包含完整身体和收势，站姿落脚位置一致。其他动作只缓存压缩字节，不创建额外播放器。启用减少动态效果时显示对应静止姿势。

缺少角色素材时，公开程序继续显示通用船只；高级推理形态和增强桌宠需要对应媒体，不能把没有素材误报成安装失败。

## 在 Codex 中注册 Mini 智能伙伴

增强桌宠跟随原生 Mini 开关；不会自行新增一个独立桌面快捷方式。当前兼容的注册名是「路飞 · 航海版」。需要自己准备符合 Codex 智能伙伴要求的 spritesheet.webp；增强视频不是原生 Mini 图集，两者用途不同。

在个人 Codex 目录的 pets/luffy-voyage 下放置 spritesheet.webp 和 pet.json。默认个人目录是 `%USERPROFILE%\.codex`。pet.json 内容如下：

```json
{
  "id": "luffy-voyage",
  "displayName": "路飞 · 航海版",
  "description": "本地航海主题智能伙伴",
  "spritesheetPath": "spritesheet.webp"
}
```

在 Codex「设置 → 迷你界面和智能伙伴」刷新列表，选中该智能伙伴，再点击「显示 Mini」。用 MoonlightCodex.exe --dreamskin 启动并建立有效连接后，程序会用单个增强浮窗接管该 Mini 的显示；右键切换三形态及各自六招。

此接入依赖当前 Windows Codex 的 Mini 标记和本地注册格式，其他版本可能需要适配。普通 Codex 没有可用的已验证连接时，程序只打开或复用原生窗口，不承诺可以注入动画与桌宠。
