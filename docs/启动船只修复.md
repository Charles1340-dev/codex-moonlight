# 0.2.29 启动船只显示修复

船图并未丢失。原生开场将 2.1 MB 左右的 PNG 转成更长的 Base64 地址，然后通过 --ship-atlas CSS 自定义变量转传。地址超过 Chromium 的变量值长度限制，船体的计算 background-image 变成 none，虽然位置、尺寸和透明度均正常，画面仍没有船。本地预览使用很短的文件地址，因此之前未暴露问题。

现在将图片地址直接设置到两个船体图层的 background-image，保留原有图集裁切、换船、海浪与位置动画，不修改原生窗口或降低媒体策略。

新增 npm run test:startup：在真实 Electron 渲染器中，使用 2266818 字符的原创红蓝 PNG 地址，分别验证旧图集、新图集的计算图片与实际像素；无可选素材时验证两艘通用帆船。修复前实际绘制像素为 0，修复后两个场景均超过 10 万个目标色像素。

发布前还应检查真实 Codex 同窗播放、结束后的工作区衔接，以及本机已安装目录使用新构建。

同次检查发现旧辅助程序的 GPU 进程曾持续占用约 5 GB 私有内存，系统出现分配失败。0.2.29 对桌宠窗口隐藏增加视频暂停，恢复显示时重用原播放器；正式包 smoke 检查隐藏/恢复行为。该变化减少不必要的后台播放，长期 GPU 占用仍应结合实际设备观察。
