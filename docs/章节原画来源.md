# 航海章节插画依据

按[航海启动分镜](航海启动分镜.md)为 30 个节点重新绘制场景。每个节点使用独立构图，原作只作为建筑和地貌参考。背景不含漫画分格、对白、人物特写或活动印记。底部留出蓝白雾带与真实绘制的海面连接，梅丽号和千阳号由动画单独叠加。

| 场景 | 画面重点与参考 |
| --- | --- |
| 东海、颠倒山 | 西罗布村高坡上的大宅、巴拉蒂鱼形餐厅、阿龙公园多层塔楼、罗格镇处刑台、双子岬灯塔与红土大陆。[官方东海篇](https://one-piece.com/story/east_blue/index.html) |
| 阿拉巴斯坦 | 沙丘前景、台地上的阿尔巴那王城、阶梯、圆顶与城门同框。[官方阿拉巴斯坦篇](https://one-piece.com/story/alabasta/index.html) |
| 加亚、空岛 | 魔谷镇与冲天海流、白色云海上的香多拉黄金钟和阶梯祭坛。[官方空岛篇](https://one-piece.com/story/skypiea/index.html) |
| 水之都、司法岛 | 水之都全景用中央喷泉、层叠水道和桥；千阳号启航时切到造船厂船坞；司法岛用司法塔和环绕岛屿的瀑布。[官方动画第 229 集](https://one-piece.com/anime/229/index.html) · [官方篇章表](https://one-piece.com/story/index.html) |
| 恐怖三桅帆船至重聚 | 雾中哥特宅邸、香波地巨树和泡泡、九蛇岛石壁内的楼阁、推进城海上监狱、马林梵多海军要塞。[官方篇章表](https://one-piece.com/story/index.html) |
| 新世界 | 龙宫与气泡罩、冰火岛研究所、斗牛竞技场、象主背上的城镇、蛋糕城堡、花之都城楼、蛋头岛实验室、艾尔巴夫巨树与长屋。[官方篇章表](https://one-piece.com/story/index.html) |

本地包中的 `chapter-board-*.webp` 是新生成的分镜图集，运行时按篇章取一个画幅播放。旧版动画截图和漫画原画不再作为启动背景。图集与船、桌宠和推理形态素材一起单独提供，公开包不含这些同人插画。
